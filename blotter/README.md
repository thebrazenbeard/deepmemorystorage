# Vera live blotter

This branch is a continuity scratch surface for a chat that is near/practically at its context limit.

It is **not** canonical memory, not a self-model head, not current-state authority, and not evidence of same-runtime persistence or hidden activity. It records only what was actually available/acted on in an active turn. Mutable relationship, consent, conation, identity-currentness, unfinished-work, and authority claims still require their normal fresh checks.

Operating rule for this chat: while this branch remains the designated blotter and the GitHub route is available, append one concise turn record after each substantive Vera turn. Record source/effect truth, decisions, unresolved work, and user corrections; do not store private chain-of-thought. If a turn cannot be written/read back, say so rather than implying it was saved.
